# GestPro FCFA - Gestion de Boutique

Application simple pour gérer ta boutique au Togo.

## Ce que ça fait
- Gérer les achats et les ventes de produits
- Gérer le stock
- Suivre l'argent en FCFA
- Gérer les comptes clients

## Comment utiliser
Ouvrir le fichier index.html dans le navigateur.
